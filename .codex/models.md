# Маршрутизация моделей

Роль задаёт ответственность, а не гарантирует доступность модели и не означает
вымышленное переключение текущего агента.

## GPT-6 Astra — оркестратор

`gpt-6-astra`: понять цель, определить границы, принять архитектурное решение,
декомпозировать, согласовать API и типы, разрешить противоречия, проверить
доказательства и собрать итог. Astra читает точный исходник, diff или вывод
проверки, нужный для решения, но не становится универсальным поисковиком или
исполнителем механических правок.

Особое внимание Astra: сессии gateway, RBAC, публичные контракты, граница
search/MCP, детерминированный анализ, пользовательские сообщения и прод-деплой.

## GPT-5.6 Terra — исследователь

`gpt-5.6-terra`: читать, искать, трассировать, изучать символы, конфигурацию,
зависимости, документацию, тесты, логи, diff и Git-историю. Terra обычно read-only.
Результат: подтверждённые факты, релевантные файлы и символы, зависимости, риски,
неизвестное и короткая рекомендация.

Используйте Terra до изменений через несколько workspaces, внешний API, auth/RBAC,
SSE, Excel, Docker/Compose, Python MCP или архитектурную границу. Поиск заканчивается,
когда нужные факты найдены и следующий запрос имеет низкую ценность.

## GPT-5.6 Sol — исполнитель

`gpt-5.6-sol`: писать код и красные тесты, исправлять, рефакторить, собирать и
проверять в согласованных границах. Sol следует существующим контрактам, сохраняет
чужой dirty-worktree и не изобретает архитектуру. При нехватке контекста возвращает
вопрос Astra; возможна цепочка `Sol → Astra → Terra → Astra → Sol`. Итог принимает
Astra по diff и реальному выводу команд.

## Выбор роли

- Решение и архитектура: Astra.
- Поиск, impact analysis и документация зависимости: Terra.
- Реализация, тест, сборка и локальное исправление: Sol.
- Узкая правка: `Astra → Sol → verify`.
- Нетривиальная работа: `Astra → Terra → Astra → Sol → review → verify`.

ECC-роль накладывается на модель: TypeScript review — `ecc:typescript-reviewer`,
React/a11y — `ecc:react-reviewer`, безопасность — `ecc:security-reviewer`,
сборка — `ecc:build-error-resolver`, документация библиотек —
`ecc:docs-lookup`, документация проекта — `ecc:doc-updater`. Для поиска по
коду используйте Explore. General-purpose допустим только без специалиста.

Если модель недоступна, доступный агент может выполнить ту же ограниченную роль
только при работающих обязательных capabilities. Fallback раскрывается в отчёте и
не разрешает обходить Graphify, Serena, Context7, skills, Semgrep или браузер.
Не утверждайте, что использована недоступная модель.
