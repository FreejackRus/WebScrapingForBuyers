# Граница IT-ассортимента

Price Radar ищет IT-товары и их комплектующие. В scope входят компьютеры,
ноутбуки, серверы, смартфоны, планшеты, мониторы, периферия, сеть, печать,
накопители, процессоры, видеокарты, память, платы, питание, охлаждение, кабели,
адаптеры и совместимые аксессуары.

Бытовая техника, одежда, продукты, товары для животных и прочие не-IT
категории не должны попадать в подсказки и предложения. Поиск с явно
не-IT запросом отклоняется. Неизвестный текст без типа товара или артикула
просит уточнить запрос; артикул допускается, только если итоговая карточка
содержит подтверждение IT-категории.

Устройство и аксессуар для него — разные товары: чехол для iPhone не
сравнивается по цене с iPhone. При этом отдельный поиск чехла разрешён.
Классификация детерминированная и живёт в `apps/search`; LLM не решает,
какие товары допускать в выдачу. Новые категории и пограничные случаи
добавляются через тесты, а не через широкие совпадения по бренду.
