# Офисный агент Price Radar (Ситилинк)

Ситилинк закрыт защитой Qrator: с IP сервера (дата-центр) он отвечает `429`, и раньше
его приходилось «прогревать» вручную через VNC. С офисного IP обычный headless Chrome
проходит без прогрева. Агент работает на офисном компьютере и отдаёт серверу результаты
поиска Ситилинка.

```
сервер: search ──► 172.29.0.1:18091 (office-relay) ──► 127.0.0.1:18091 ══ обратный SSH ══► офис: агент ──► citilink.ru
```

- Входящие подключения в офис не нужны: туннель открывает офисная машина.
- Ключ туннеля на сервере ограничен: только `-R 127.0.0.1:18091`, без shell.
- Агент слушает только `127.0.0.1`, кэширует ответы 20 минут и делает не больше одного
  запроса к Ситилинку раз в 2,5 секунды.
- Компьютер выключен → поиск идёт через прежний MCP-коннектор (скорее всего `429`),
  остальные источники не затронуты.

## Установка (один раз)

```bash
cd scripts/office-agent
AGENT_SERVER=root@<сервер> ./install.sh
```

Скрипт ставит зависимости, создаёт ключ `~/.ssh/price_radar_tunnel`, systemd-сервисы
`price-radar-agent` и `price-radar-tunnel` (пользовательские) и печатает строку для
`~/.ssh/authorized_keys` на сервере.

## Проверка

```bash
systemctl --user status price-radar-agent price-radar-tunnel
curl -s 'http://127.0.0.1:18091/citilink/search?q=kingston%20kc3000'   # на офисной машине
```

На сервере: `curl -s http://172.29.0.1:18091/health`.

Переменные агента: `AGENT_PORT` (18091), `AGENT_CHROME` (/usr/bin/google-chrome),
`AGENT_CACHE_MINUTES` (20), `AGENT_PACE_MS` (2500), `AGENT_TOKEN` (если задан — сервер
передаёт его в `OFFICE_AGENT_TOKEN`).
